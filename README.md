# Site de Casamento — Pamella & Thiago

Website desenvolvido com HTML, CSS e JavaScript para apresentar informações, detalhes da cerimônia, recepção e interatividade para os convidados do casamento de Pamella e Thiago.

## Sobre o Projeto

Este projeto consiste na página web comemorativa e informativa criada especialmente para o evento de casamento. O site foi projetado com foco em elegante acessibilidade, design responsivo para dispositivos móveis e facilidade de navegação para os convidados.

### Funcionalidades
- **Contagem Regressiva:** Cronômetro dinâmico em JavaScript calculando o tempo restante até a data do grande dia.
- **Informações do Evento:** Detalhes de local, horário e orientações para os convidados.
- **Manual dos Convidados / Trajes:** Orientações visuais sobre o dress code e paleta de cores.
- **Design Responsivo:** Leiaute adaptado para navegação fluida em smartphones, tablets e desktops.

---

## Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização personalizada, animações e layout responsivo via Flexbox/Grid.
- **JavaScript (Vanilla):** Lógica para contagem regressiva e interatividade dos elementos da página.
